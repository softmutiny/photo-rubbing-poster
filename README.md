# 照片拓印海报

一个把照片分步做成拓印海报的 Codex Skill。

先把主体做成黑白拓印素材，保住大块墨色和细刻线，再做克制套色、无字构图与文字排版。助手负责观察照片、组织提示词和衔接步骤，不需要用户逐步准备提示词。

![帘外听风：墨色构图修订版](references/images/approved-poster.jpg)

## 它适合做什么

- 从器物、植物、鸟类或其他轮廓清楚的照片中提取拓印主体。
- 只制作黑白拓印中间素材，或沿用素材继续调色与排版。
- 分析并修复做旧滤镜感、全金线、纸纹过重，以及主体与色块关系呆板的问题。

它是风格化重绘流程，不适合要求产品照片或标识逐像素保持不变的修图任务。配色和版式根据照片调整，不固定套用示例中的灰蓝、暖褐与竖排书法。

## 使用

把包含 `SKILL.md` 的本仓库目录放到 Codex 技能目录，文件夹命名为 `photo-rubbing-poster`。

调用名：`$photo-rubbing-poster`

可以这样说：

> 使用照片拓印海报，把这张照片先做成黑白拓印素材，先别排版。

或：

> 使用照片拓印海报，把这张照片分步做成完整海报。构图和提示词你来判断，保留中间图。

图像生成与编辑使用环境中的内置图像工具。无需教程推广的软件或账号；本仓库不包含模型 API 密钥。
