# 已验证案例：帘外听风

这个案例用于学习判断，不是固定版式或固定配色的模板。以下图片均为低流量参考，原始工作文件不构成技能运行依赖。

- [bw-rubbing.jpg](images/bw-rubbing.jpg)：分步制作得到的黑白母版。重点看完整黑墨形、细白结构线、自然缺墨及主体识别性。
- [approved-poster.jpg](images/approved-poster.jpg)：用户最后认可的墨色构图版。用户评价“还不错，已经没有 AI 味了”。它是本案例的基准，不是对每处细节的普遍认证；纸纹仍略偏重。
- [rejected-one-shot.jpg](images/rejected-one-shot.jpg)：早期直接从照片做整张海报的小样。用户指出与教程成品差距大。粗颗粒、帘线、粗斜杆、大字与全旧金共同挤占画面，不能只因有纸底和书法便认定成功。

首次可先看母版与认可版；理解“为什么之前没做对”时再看早期反例。不要为了加载案例一次读完全部图片。

## 实际经历与可复用判断

1. 早期整张生成：保留了过多照片结构，纹理重，标题和主体争抢注意力。后面缩小主体、增加留白，虽干净，却没有自动产生空间节奏。
2. 用户要求先制黑白素材、先别排版：这一步让墨块、结构线与主体保真有了单独可判断的中间结果。此类明确阶段限制必须遵守。
3. 黑白素材调成透明旧金层，叠加灰蓝与暖褐纸底，再独立加题字：流程变清楚，但全金处理仍削弱了母版实心墨块，主体像等亮金线描画。
4. 对照参考分析：参考枝条能斜向展开、切分空白；挂饰天然偏窄竖形，不能机械复制参考的物体。需要调整位置关系，也不能把“更多留白”当成万能修复。
5. 最后两步修订：先恢复大面积深灰蓝墨色，只在边缘及局部留旧金；再将挂饰向左移、分色线略向左收。用户认可这一版。

这证明了“黑白母版 → 保留墨块的套色 → 构图 → 排字 → 针对主因修订”的价值，不证明案例中的颜色、左右分割、标题方位适用于所有照片。

## 认可版可观察到的特征

- 主要铃铛与橘片由平面深色承重，细线说明形状，而非满画面发亮。
- 旧金主要落在标题、少量边缘和次要局部，图中有明暗主次。
- 主体与分色线错开，草叶向左自然展开；保持同一串挂饰，没有凭空补鸟、花或枝条。
- 标题为“帘外听风”，右上错落两列；题注为“一帘竹影 / 几声清响”。这些文字只属于本案例。
- 背景竹帘影迹低于主体，纸纹不应继续加强。认可版仍有轻微厚重纸纹，后续精修可以单独减弱。

## 后续使用

新照片先识别自己的主形和方向；参考本案例的墨色层级、工序与纠错逻辑。若用户明确要沿用此版式，可用认可图作风格参考，同时提供新照片或新黑白母版作主体来源，并明确排除案例里的铃铛、橘片与文字。
